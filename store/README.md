# Play Store graphics

Assets for [Google Play Console](https://play.google.com/console) → **Grow** → **Store presence** → **Main store listing**.

| File | Use | Spec |
|------|-----|------|
| `play_store_icon_512.png` | **App icon** (high-res icon) | **512 × 512** px, 32-bit PNG with alpha, max 1 MB |
| `play_store_feature_graphic.png` | **Feature graphic** (top of listing) | **1024 × 500** px, PNG or JPEG, no transparency |

Files in this folder are exported at those exact sizes (dark background + neon “A” style, aligned with the in-app icon).

After upload, Google may show additional crop/safe-zone previews—adjust padding in a design tool if anything is clipped.

**Upload:** Console → **Main store listing** → *App icon* / *Feature graphic* → upload the matching PNG.
